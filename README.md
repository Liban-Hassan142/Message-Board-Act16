Project Overview

This application is a Firebase-powered message board built with Flutter.

The app allows users to:

Register using Firebase Authentication
Sign in and sign out
Create a Firestore user record
Create messages
View live-streamed messages
Edit their own messages
Delete their own messages
Access data protected by Firestore Security Rules


Firebase Authentication uses Email/Password sign-in.

Supported operations:

Register
Login
Logout
Auth state management is handled through authStateChanges()
